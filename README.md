# Hospital Patient Analysis Dashboard

## Project Overview
This project analyzes hospital patient data using Python, Excel, and Power BI to identify patterns in patient admissions, medical conditions, insurance billing, and length of hospital stay.

## Objectives
- Clean and prepare hospital patient data.
- Analyze patient admission and discharge dates.
- Calculate patient length of stay.
- Compare average billing amounts across medical conditions.
- Visualize patient data through an interactive Power BI dashboard.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Excel
- Power BI

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. Patient length-of-stay calculation
4. Analysis of billing and medical conditions
5. Dashboard creation and visualization

## Key Features
- Hospital patient KPI cards
- Monthly admission analysis
- Medical condition analysis
- Insurance billing analysis
- Patient length-of-stay analysis
